# Ozon Fresh Filter

Расширение для Google Chrome / Microsoft Edge, которое помогает находить самые выгодные товары в Ozon Fresh.

## Возможности

- автоматический сбор всех товаров из открытой категории;
- фильтрация по максимальной цене;
- фильтрация по минимальной скидке;
- зелёные слова (предпочтительные товары);
- красные слова (товары, которые не нужно показывать);
- скрытие неподходящих карточек прямо на странице Ozon;
- сортировка найденных товаров;
- экспорт результатов в CSV.

---

## Как установить

### 1. Скачать проект

Скачайте архив проекта и распакуйте его в любую папку.

Например:

```
D:\Projects\OzonFreshFilter
```

---

### 2. Открыть страницу расширений Chrome

Перейдите:

```
chrome://extensions/
```

---

### 3. Включить режим разработчика

В правом верхнем углу включите:

```
Developer mode
```

---

### 4. Загрузить расширение

Нажмите

```
Load unpacked
```

и выберите папку проекта.

Не архив.

Именно папку, содержащую

```
manifest.json
```

---

### 5. Обновить страницу Ozon

Если Ozon уже был открыт —
обязательно обновите вкладку.

---

### 6. Запустить

Откройте любую категорию Ozon Fresh.

Например

```
https://www.ozon.ru/category/supermarket-gotovye-blyuda-9521000/
```

Нажмите значок расширения.

Откроется боковая панель.

Нажмите

```
Собрать все товары
```

---

## Как пользоваться

После завершения сканирования можно:

- ограничить максимальную цену;
- задать минимальную скидку;
- указать зелёные слова;
- указать красные слова;
- отсортировать товары;
- экспортировать список в CSV.

Красные слова полностью скрывают товары.

Например

```
тыква
печень
оливки
```

Зелёные слова помогают быстрее находить интересующие товары.

Например

```
курица
сыр
творог
```

---

## Обновление расширения

После изменения файлов:

1. открыть

```
chrome://extensions/
```

2. нажать кнопку

```
Reload
```

3. обновить вкладку Ozon.

---

## Разработка

Для разработки рекомендуется использовать Visual Studio Code.

Структура проекта:

```
manifest.json      — настройки расширения

service-worker.js  — запуск расширения

content.js         — парсинг страницы Ozon

content.css        — оформление карточек

sidepanel.html     — интерфейс

sidepanel.js       — логика панели

sidepanel.css      — стили панели
```

---

## Ограничения

Расширение работает только с открытой страницей Ozon.

Сбор товаров происходит автоматически путём прокрутки страницы.

Работа зависит от текущего аккаунта Ozon, выбранного адреса доставки и доступности товаров.

При изменении структуры сайта Ozon может потребоваться обновление парсера.

---

## Планы

Планируемые функции:

- история изменения цен;
- поиск действительно выгодных скидок;
- анализ состава продуктов;
- категории ("полезное", "вредности", "остальное");
- фильтр по цене за 100 г;
- избранные товары;
- скрытие отдельных товаров по ID;
- поиск минимальной цены среди аналогов.
