# Ozon Fresh Filter

Расширение для Chrome и Edge, которое собирает товары Ozon Fresh во внутреннюю боковую панель и помогает быстро отбирать выгодные предложения.

## Возможности v0.6.0

- сбор товаров из внутренней пагинации Ozon без ручной прокрутки всех страниц;
- фильтры по цене, скидке, рейтингу, количеству отзывов, категориям и словам;
- компактный вывод рейтинга и отзывов;
- пометка товаров «Съешьте скорее»;
- категории с быстрым исключением ненужных групп, например супов;
- белки, жиры, углеводы и калорийность в карточках;
- добавление одной штуки товара в корзину штатной кнопкой Ozon;
- сортировка по выгодности, цене, скидке, рейтингу, отзывам и экономии;
- экспорт результатов в CSV.

## Установка

1. Скачайте репозиторий и распакуйте его.
2. Откройте `chrome://extensions/` или `edge://extensions/`.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку `ozon-fresh-filter-mvp`, в которой лежит `manifest.json`.
6. Откройте страницу Ozon Fresh и обновите её через `Ctrl + Shift + R`.
7. Нажмите значок расширения.

## Использование

Нажмите «Собрать товары», настройте фильтры и исключите ненужные категории. Кнопка «БЖУ» загружает характеристики для показанных после фильтрации товаров. Кнопка «В корзину» добавляет одну штуку через интерфейс Ozon.

Загрузка БЖУ выполняет отдельный запрос страницы каждого товара. Если Ozon не публикует пищевую ценность или изменил формат страницы, данные для такого товара могут отсутствовать.

## Структура

Основной код расширения находится в папке `ozon-fresh-filter-mvp`:

- `parser.js` — разбор товаров, категорий, рейтинга и БЖУ;
- `bridge.js` — сбор, фильтрация, загрузка характеристик и работа с корзиной;
- `page-interceptor.js` — перехват и выполнение внутренних запросов страницы;
- `service-worker.js` — боковая панель и фоновая вкладка для корзины;
- `sidepanel.html`, `sidepanel.css`, `sidepanel.js` — интерфейс панели.

Работа расширения зависит от текущей структуры сайта Ozon, выбранного адреса доставки и доступности товаров.
