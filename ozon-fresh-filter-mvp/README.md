# Ozon Fresh Filter MVP v0.2

## Изменения

- Быстрые прыжки в конец страницы с ожиданием 300 мс.
- Остановка после 4 проходов без новых товаров, максимум 150 проходов.
- Уже обработанные ссылки повторно не разбираются.
- Процент жирности вроде `82%` больше не считается скидкой.
- Явная скидка распознаётся только как `−42%` или `-42%`; иначе вычисляется по старой и новой цене.
- Панель привязана к конкретной вкладке Ozon, на которой нажали значок расширения.
- Для другой вкладки панель нужно открыть отдельно.

## Установка

1. Распакуйте архив в постоянную папку.
2. Откройте `chrome://extensions/` или `edge://extensions/`.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение» и выберите папку `ozon-fresh-filter-mvp`.
5. Обновите страницу Ozon.
6. Нажмите значок расширения на нужной вкладке каталога.

## Редактирование

Удобнее всего в VS Code: `File → Open Folder` и выбрать распакованную папку.

- `content.js` — сбор, прокрутка, распознавание цены и скидки.
- `sidepanel.js` — фильтры и список результатов.
- `sidepanel.html` / `sidepanel.css` — интерфейс.
- `service-worker.js` — привязка панели к вкладке.
- `manifest.json` — конфигурация расширения.

После изменений сохраните файлы, нажмите «Обновить» у расширения на `chrome://extensions/` и перезагрузите страницу Ozon.

## Исправление 0.2.1

Боковая панель теперь открывается штатным механизмом Chrome `openPanelOnActionClick`, поэтому ошибка
`sidePanel.open() may only be called in response to a user gesture` больше не возникает. Панель заранее
настраивается отдельно для каждой вкладки Ozon и отключается на остальных сайтах.
