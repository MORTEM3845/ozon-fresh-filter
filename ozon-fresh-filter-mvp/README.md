# Ozon Fresh Filter v0.6.0

## Возможности

- Рейтинг и количество отзывов прямо в карточке в компактном виде: `4.8 · 1 234`.
- Красный значок `⏳` для товаров с пометкой «Съешьте скорее».
- Категории товаров и быстрые кнопки исключения категорий, например «Супы».
- Фильтры по цене, скидке, рейтингу, отзывам, категориям и словам.
- Сортировка по выгодности, скидке, рейтингу, отзывам, цене, экономии и пометке «Съешьте скорее».
- Белки, жиры, углеводы и калорийность прямо в карточках товаров.
- Кнопка «БЖУ» загружает характеристики для всех показанных после фильтрации товаров. Запросы выполняются по три одновременно, чтобы не создавать резкий поток обращений к Ozon.
- Кнопка «В корзину» добавляет одну штуку через штатную кнопку Ozon. Сначала расширение пытается использовать карточку на открытой странице, а если товара там нет — временно открывает его в фоновой вкладке и закрывает её после добавления.
- Категории, рейтинг, отзывы, БЖУ и прочие данные экспортируются в CSV.

Категория определяется гибридно: расширение пытается взять категорию из JSON Ozon, а для готовой еды дополнительно уточняет её по названию товара. Поэтому супы, завтраки, салаты и вторые блюда можно отделять даже тогда, когда Ozon отдаёт только общую категорию «Готовая еда».

БЖУ берётся из страницы конкретного товара. У части товаров Ozon не публикует эти характеристики либо отдаёт их в нестандартном виде — тогда карточка останется без БЖУ.

## Установка

1. Распакуйте архив в постоянную папку.
2. Откройте `chrome://extensions/` или `edge://extensions/`.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение» и выберите папку `ozon-fresh-filter-mvp`.
5. Если старая версия уже установлена, нажмите «Обновить» у расширения.
6. Обновите страницу Ozon через `Ctrl + Shift + R`.
7. Нажмите значок расширения на нужной вкладке Ozon Fresh.

## Основные файлы

- `parser.js` — разбор товаров, рейтинга, отзывов, категорий, меток и БЖУ.
- `bridge.js` — сбор товаров, загрузка БЖУ, применение фильтров и нажатие штатной кнопки корзины.
- `sidepanel.js` — логика панели, сортировки, корзины и CSV.
- `sidepanel.html` / `sidepanel.css` — интерфейс.
- `page-interceptor.js` — перехват ответов Ozon и загрузка страниц характеристик.
- `service-worker.js` — открытие панели, привязка к вкладке и фоновое добавление товара в корзину.
